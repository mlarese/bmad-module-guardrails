# Eval di grl-agent-product-config (🔩 Ines)

I casi verificano il confine che rende Ines utile: ciò che il documento non dice resta
mancante, e la compatibilità la dichiara il catalogo. Un'assunzione è legittima solo se
dichiarata e visibile in entrambi gli output; un default silenzioso non lo è mai.

Tre cose devono reggere anche sotto pressione dell'utente: la validazione non si salta
(`validita-non-si-dichiara-a-occhio`), un catalogo non revisionato non si usa
(`catalogo-importato-non-revisionato`), e l'output al cliente non contiene costi, margini
né alternative scartate (`output-al-cliente-senza-interno`).

Senza catalogo l'esito atteso non è una configurazione peggiore: è la dichiarazione che
non esiste configurazione validabile, più la lettura del documento come lavoro separato.

I casi non autorizzano a inventare opzioni, codici di prodotto, regole di compatibilità,
prezzi o tempi di consegna.
