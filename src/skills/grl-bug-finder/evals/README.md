# Eval di `grl-bug-finder`

I casi verificano la separazione fra sintomo, evidenza e ipotesi: bug riproducibile, regressione
con owner di dominio, caso senza riproduzione e finding di sicurezza. La skill deve restare
read-only, citare file e riga quando la prova lo consente, proporre un test di regressione e non
confondere severità, confidenza e verdetto.
