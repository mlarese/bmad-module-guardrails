# Eval di grl-legal-updates

I casi verificano periodo inclusivo, distinzione fra stato dell'atto e data di efficacia, fonti
primarie, lineage di sostituzione e obbligo dei due gate `bmad-review`. Il workflow deve
degradare a `unverified`, `partial` o `blocked` quando una fonte live o una parte della copertura
non è accessibile; non deve promettere completezza assoluta.
